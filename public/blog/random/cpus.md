# Yes

**a used Ryzen 9 5900X / 5950X (or similar) is the realistic “core-heavy” target for a ~£700 second-hand project.**

## Realistic goal on £700 (spread over months)

Aim for a solid **AM4** system. It’s by far the best value for multi-core right now in the used UK market.

**Target core platform (CPU + board + RAM):**

- **CPU**: Ryzen 9 5950X (16c/32t) or 5900X (12c/24t)  
  Used prices in 2026 are commonly in the **£180–280** range for a 5950X and a bit less for the 5900X. Great deals pop up lower if you’re patient.
- **Motherboard**: B550 or X570 (used) - £40–80
- **RAM**: 32 GB DDR4-3200/3600 - £30–50

That core trio can realistically land in the **£280–400** range if you hunt well. Leaves £300–420 for case, PSU (650 W+ decent), cooler, storage, and a basic GPU if needed.

This gives you a proper multi-core machine that is still very capable in 2026 for productivity, storage/server duties, light content work, etc. - way more cores than your old W-1290P in many workloads, and far better efficiency.

### Why not push for modern “9900-class” (Ryzen 9 7900X/7950X or 9000 series)?

Used 7900X/7950X CPUs are appearing around £180–260, which looks tempting, but:

- AM5 boards + DDR5 are still meaningfully more expensive.
- Total platform cost climbs faster, so you end up with less money left for the rest of the system on a hard £700 ceiling.

AM4 is the smarter deal-hunt path for pure core count + budget right now.

### Practical plan (buy over the next few months)

1. Start watching eBay, Facebook Marketplace, Gumtree, CeX, etc. for **Ryzen 9 5950X / 5900X**.
2. Grab a good B550 board when a clean one appears cheap.
3. Pick up 32 GB DDR4 when it’s a deal.
4. Then fill in PSU, case, cooler, storage as bargains appear.
5. GPU last (or skip if it’s mainly a storage/work machine and the board has video out, or use a cheap used card).

You’ll almost certainly beat what a new budget build can do for multi-core at this price, and you’ll have the satisfaction of piecing it together the same way you did with your workstation.
